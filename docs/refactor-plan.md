# Markdown WeChat Publisher 重构

## 目标

保留预览、可视化主题编辑、复制、多公众号、封面裁剪和 APIMart 生图。保留 Obsidian MarkdownRenderer、highlight.js、Cropper.js；重写存在状态串扰、重复渲染和不安全回写的核心流程，不重做界面设计。

本轮不升级版本、不推送或发布远程。完成后构建并复制 main.js、styles.css、manifest.json 到本地 markdown-wechat-publisher 插件目录，不覆盖 data.json。账号、密钥、自定义主题保留；旧图片缓存缺少账号和内容指纹，不继续复用，不恢复草稿缓存。

## 已确认规则

- 内置主题只读，编辑时创建自定义副本。
- 生图任务独立于弹窗，关闭后继续，重新打开可查看进度。插件卸载后停止后续轮询和文章回写，不承诺退出应用后继续任务。
- 四个入口使用同一份标准渲染结果，出口只适配图片资源地址，不修改排版。
- 保留 image-prompt 注释。回写前校验文章最新内容，不按旧行号覆盖正文；冲突时保留生成图片并明确提示。
- 每个发布任务固定文章、主题、公众号快照；封面与公众号绑定。

## 核心链路

```text
文章与主题快照 / 示例 Markdown
  -> Markdown 渲染
  -> DOM 清理
  -> 微信兼容结构转换
  -> 主题 CSS 生成
  -> 统一内联样式与标准渲染结果
  -> DOM 预览 / 剪贴板资源适配 / 微信资源适配
```

## 模块方向

```text
src/
  core/
    render/        统一文章渲染入口
    transform/     DOM 转换、清理、公式、Mermaid、代码块、列表、图片
    theme/         主题类型、预设、CSS 生成、主题服务
    output/        HTML 序列化、CSS 内联、剪贴板和发布输出

  features/
    preview/       文章预览视图与控制
    theme-editor/  样式编辑器
    publish/       发布弹窗与发布流程
    settings/      设置管理

  integrations/
    obsidian/      Obsidian 文件、图片、Markdown 渲染适配
    wechat/        微信 API、素材上传、草稿发布

  shared/          日志、错误、通用工具
```

## 交付标准

1. 全量测试文章覆盖所有内置主题、自定义主题、代码、列表、图片、公式和图表；同宽度预览与导出的结构及关键样式一致。
2. 多提示词、重复提示词、代码示例、生成期间文章变化、关闭重开和重复点击不会误写正文或重复提交。
3. 账号切换不混用封面和缓存，图片内容变化后重新上传；并发配置保存不丢数据。
4. 快速切换文章/主题不显示过期结果，组件和资源正确清理。
5. 类型、官方 ESLint、业务测试、浏览器测试和构建通过。微信与收费生图使用 mock；最终真实公众号效果集中验收一次。
6. 修复市场已报告错误；版本/tag/release 资产一致性加入发布门禁。真实市场复审在后续获准发布时进行。
